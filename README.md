# RecallStack

RecallStack 是一个采用背单词式学习流程的 Java 八股复习工具。当前版本内置 165 张 Java 后端面试重点卡片，通过主动回忆和 FSRS 间隔重复安排每日任务。

> 当前版本：`v0.1.0-beta.1`。核心学习流程已经可用，卡片内容和交互仍在持续校对与优化。欢迎通过 GitHub Issues 反馈内容错误和使用问题。

## 当前功能

- 今日新卡与到期复习任务
- 问题先行、答案揭示和四档掌握评分
- 当日学习队列与进度持久化，刷新后继续当前任务
- 仅查看刚完成的上一题，并可替换误点的评分
- FSRS 复习调度
- 牌组浏览、S/A 重要度筛选、主题进度和学习统计
- 薄弱卡识别与未来 7 天复习预测
- 每日任务设置与学习进度重置
- 学习数据 JSON 备份与恢复
- IndexedDB 本地持久化
- 响应式桌面与移动端界面
- PWA 离线缓存与 GitHub Pages 部署

## 本地运行

要求 Node.js 20 或更高版本。

```bash
npm install
npm run dev
```

启动后访问终端显示的本地地址。手机和电脑在同一局域网时，也可以访问终端显示的 Network 地址进行真机测试。

## 验证命令

```bash
npm run lint
npm test
npm run build
npm run test:e2e
```

Playwright 默认使用本机 Chrome，分别覆盖桌面和 Pixel 7 移动端视口。

## 数据说明

学习数据只保存在当前浏览器的 IndexedDB 中，不会上传到服务器。可在设置页导出 JSON 备份；恢复备份会先校验文件，再完整替换当前浏览器中的设置、复习状态、复习日志和每日会话。备份不包含内置牌组内容，因此文件更小，也不会覆盖应用升级后的题库。

薄弱卡判定规则为：最近一次评分为“忘记”，或最近 5 次中至少 2 次评分为“忘记/吃力”。未来 7 天预测按已学习卡片当前的 FSRS 到期日期统计。

内置牌组覆盖 11 个专题，共 72 张 S 级卡片和 93 张 A 级卡片；每张卡片包含分数、关键词、核心回答、详细解释、回答要点、延伸追问和来源定位。

卡片由 `scripts/generate-java-cards.mjs` 根据分级 Markdown 和 PDF 提取文本生成，生成后的静态数据已包含在仓库中，正常运行应用不依赖原资料。需要重新生成时，可执行：

```bash
npm run generate:java-cards -- --source "D:/path/to/Java八股重点分级" --pdf-markdown "D:/path/to/pdf-markdown"
```
