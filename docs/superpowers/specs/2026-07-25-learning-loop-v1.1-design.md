# RecallStack v1.1 学习闭环设计

## 范围

本次实现每日会话持久化、仅上一题查看与重评、JSON 备份恢复、薄弱卡识别和未来 7 天复习预测。账号、云同步、通知、笔记和 AI 拆卡不在本次范围。

## 每日会话

首次打开首页或学习页时，按当前 FSRS 状态和每日限额生成当天队列，并保存卡片 ID、是否新卡、当前位置和最近一次评分快照。当天再次打开时复用同一队列；设置变化从下一天生效。重置学习进度时同时删除会话。

## 上一题与重评

每次评分保存评分前的 `ReviewState`、日志 ID、原评分时间和队列位置。学习页只能查看最近完成的一题，默认显示答案与原评分。重新评分时，以原评分前状态和原评分时间重新计算 FSRS，覆盖原日志与当前状态，不增加复习次数。完成新的当前题后，旧快照被替换，因此无法访问上上题。

## 备份恢复

备份格式版本为 1，包含设置、复习状态、复习日志和每日会话，不复制内置牌组内容。导入采用完整替换；先解析并校验全部数据，再在单一事务中写入。任何解析或校验错误都不得修改当前数据。

## 薄弱卡与预测

若卡片最近一次评分为“忘记”，或最近五次评分中至少两次为“忘记/吃力”，则标记为薄弱卡。统计页展示各专题薄弱数量和薄弱卡列表。未来七天预测只统计 `reviewCount > 0` 的卡片，根据当前 FSRS `due` 日期分桶。

## 验证

数据层使用 Vitest + fake-indexeddb 覆盖会话冻结、刷新恢复、重评覆盖、备份原子恢复、薄弱规则和预测分桶。React Testing Library 覆盖上一题交互及设置页备份入口。Playwright 覆盖刷新继续、重评和备份导出入口的桌面与移动端流程。
